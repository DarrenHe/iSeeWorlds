# iSeeWorlds Website v12 — Launch Polish

Date: 2026-10-01

## Scope
A restrained launch-readiness update based on v11. The visual system, content architecture and personal-brand positioning are intentionally preserved.

## Changes
- Added the single ecosystem CTA from the Book section to `goxedge.com` with source attribution parameters.
- Added canonical URL, robots directive, Open Graph, Twitter Card and JSON-LD Person/Book metadata.
- Added `robots.txt` and `sitemap.xml`.
- Added optimized responsive WebP portraits (480w / 900w); retained the original PNG as the high-resolution source asset.
- Added explicit image dimensions, hero fetch priority, async decoding and lazy-loaded footer portrait.
- Rephrased the automotive-project line to avoid listing current-client/OEM names on the personal site while preserving the professional experience claim.
- Replaced hard-coded 2027 copyright year with the visitor's current year.
- Added keyboard focus styling and a skip-to-content link.
- Added a lightweight mobile section menu without changing the desktop navigation or information architecture.
- Improved language switch accessibility with `aria-pressed` state.

## Explicitly not changed
- Visual identity, typography, color system or section order.
- Personal-site positioning; no GILTCO commercial product catalog was introduced.
- Long-form content beyond the single risk-reducing automotive-project wording adjustment.
- No framework migration or JavaScript build system added; site remains deployable as a simple static site.
